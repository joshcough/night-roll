## Tooling requests

### 1. Key picker: first dropdown should list pitches only

**Current behavior:** the first dropdown (tonic selector) lists entries like
`D / B minor` — major keys paired with their relative minors. The second
dropdown selects the mode.

**Problem:** picking `D / B minor` and then failing to set the mode leaves the
annotation as `key: D`. Silent wrong write, no warning. This is confirmed to
have happened on `matoyas-cave.rollnotes` — the file contained a bare
`[1.1] key: D` with no supporting annotation.

**Requested fix:** first dropdown lists tonic pitches only (12 pitch classes,
spelled per the analysis). Mode comes entirely from the second dropdown.
Relative-key pairings should not appear in the tonic list at all.

**Decided:** tonic-without-mode must be enterable. Finding the tonic and then
working out the mode separately is a normal part of the method, sometimes
across sessions. Floating Castle is a live example — tonic Bb recorded, mode
still unresolved.

But a tonic alone does **not** register. "Register" means applying the key to
the staff: key signature, note respelling, anything downstream that depends on
the key. That requires both tonic and mode. Until the mode is set, the tonic is
stored as a partial and the staff renders as it would with no key at all.

So the fix is not a block and not a warning — it's a distinction between
*stored* and *applied*. The UI should make it visible which state an entry is
in, so a partial can't be mistaken for a verdict the way `key: D` was.

### 2. Lasso: rectangle-only selection can't isolate the notes needed

**Current behavior:** the lasso draws a single rectangle. Selection is whatever
falls inside it.

**Problem:** the notes Josh wants are frequently not rectangle-separable —
unwanted notes sit inside the smallest box that contains the targets. Dragging
wide enough to catch what he needs also catches neighbors.

Live case: Undersea Shrine. Pulse 2 holds an offbeat D# pedal interleaved with
the chord tones, so isolating the F#–A#–C# triad means excluding pedal notes
sitting in the same region of the roll.

**Requested:** additive selection — draw a rectangle, then draw another and have
it union into the existing selection instead of replacing it. Modifier-drag is
the obvious mechanism.

**Josh's note:** additive rectangles is his first thought, not necessarily the
right design. Open to alternatives — subtractive drag, click-to-toggle on
individual notes, or constraining the lasso to a channel before it selects.
Worth Claude Code weighing in rather than building the first idea proposed.

### 3. Pitch-class highlight — find every instance of a given pitch

**Requested:** select a pitch class and have every occurrence of it highlight
across the whole song, all channels at once.

**Why:** this is the single most repeated operation in the sweep. Every mode
determination this session ran the same way — narrow to two or three candidate
modes, then hunt the file for the one or two degrees that separate them.

- Undersea Shrine: hunt A vs A#, then E vs E#.
- Ship: hunt E vs Eb, then Bb vs B natural.
- Victory: hunt Ab vs A natural, then D vs Db.

Right now that's scrolling and eyeballing, and it's where mistakes get made —
absence of a pitch is real evidence, but only if the whole file was actually
checked.

**Design notes from use:**

- Sharp-spelled input, so the selector should be by pitch class. Highlighting
  "Bb" must catch what the capture wrote as A#. The point is finding the note,
  not its spelling.
- The highlight itself is the primary output — Josh reads the count visually off
  the highlighted notes. A numeric count somewhere is a nice-to-have, not the
  point of the feature. Don't design around it.
- Zero results must read as a confident zero, not an ambiguous blank. Ruling a
  mode out depends on trusting that the pitch genuinely isn't there.
- Should respect the current key selection if one is set, so the highlight can
  be labeled by scale degree rather than letter name.

### Floating Castle — whole tone (identified, not finished)

Josh set this aside earlier as too hard, came back to it at the end of the
session, and found why it resisted.

What's in the file, bars 1-8:

- Bass opens on the tritone Bb-E, with D#/Eb also present. Second chord is the
  same shape transposed: G#-D, with a C# alongside. The two tritones sit a whole
  step apart.
- This pattern holds for the entire first eight bars. No root motion — a static
  harmonic field, deliberately withholding.
- The other two channels are mirrored across those bars, so only one needs
  analyzing.
- Melody pitches, bars 1-2: D5, E5, F#5, G#5, A#5. Five consecutive whole steps,
  no half step anywhere.

**Conclusion: this is whole-tone material, not a mode of the major scale.**

Why every standard test failed:

- The scale is fully symmetrical, so no note is privileged — every one sounds
  equally like a root.
- It contains three tritones, which is why the bass named nothing. Tritones are
  symmetrical and identify no root.
- No leading tone and no perfect fifth above the tonic.
- Therefore the standing hypothesis (bass at loop target = tonic) is not
  confirmable here. That's not a failure of the method — this music genuinely
  lacks a tonic in the sense the sweep is built around.

**Provenance gap:** the sweep records tonic Bb for this song from a prior
session, but there is no `.rollnotes` file and no derivation anywhere in the
repo. The path was never recorded. Given the above, that Bb should be treated as
unsupported until re-derived, if it's even the right question to ask.

## Exercise for a later session — whole tone

Deferred deliberately. Josh identified the scale while tired and chose to stop
rather than learn it in that state. Flagged as worth returning to fresh.

What was covered before stopping:

- There are exactly **two** whole-tone collections and they are complements.
  Starting on C: C D E F# G# A#. Starting on C#: C# D# F G A B. Twelve pitches,
  six each, no third collection.
- Every pitch outside one collection is necessarily in the other. Composers use
  this — an apparent chromatic neighbor is often the complementary collection,
  structural rather than decorative.
- Floating Castle's melody (D E F# G# A#) is in the first collection. Its D# and
  C# are in the second. Whether those are incidental or structural is the open
  question.

Not yet covered, and the actual exercise:

1. Work out which collection each pitch in the song belongs to, across all
   channels, all eight bars.
2. Decide whether the D#/C# material is a genuine second-collection presence or
   passing decoration.
3. Notation question Josh raised: how does whole-tone music get written for
   performers? Answer given briefly — no key signature, everything spelled with
   accidentals, spelling by direction (rising sharp, falling flat) and by
   whatever avoids double accidentals. Debussy is the reference. Worth doing
   properly with examples rather than in passing.
4. Open: does the sweep's notion of "opening key" even apply to a song like
   this, or does it need a separate category?
